# MediaIndex 使用手册

MediaIndex 把发现、网盘转存、整理、追更、STRM、Emby 和通知放在同一个自托管工作台。本手册按当前界面的入口和操作顺序编写。第一次使用，先连接一个网盘，完成一部电影的转存、入库和播放，再扩大目录范围与自动化。

部署文件见 [Docker Compose](../docker-compose.yaml)，项目介绍见 [README](../README.md)，版本变化见 [更新日志](../CHANGELOG.md)。文中地址、目录和密钥均为示例或占位，实际部署时请替换成自己的值。

## 1. 认识当前界面

桌面端使用左侧导航；手机端点击左上角菜单展开同一组入口。页面内的分区标签用于切换当前模块，设置按页保存。右上角可调整外观、查看活动和通知；账户菜单中的“退出登录”会结束当前会话并返回登录页，失败时会保留页面并提示重试。

| 导航 | 用途 |
| --- | --- |
| **发现** | 浏览推荐、分类和榜单，搜索媒体，核对详情、候选与转存目录。 |
| **订阅与追更** | 管理智能追更、愿望单、已存进度、缺集与人工确认。 |
| **网盘工作台** | 网盘链接、资源获取、转存和整理规则、云下载、Webhook、任务中心。 |
| **跨盘转存** | 选择 OpenList 或 CD2 通路，手动复制及配置夸克到 115 的自动补齐。 |
| **STRM 与 302** | 配置播放地址、Emby、网盘扫描范围和删除同步。 |
| **媒体服务器** | 查看 Emby 媒体库、用户、播放会话、最近入库，制作媒体库封面。 |
| **全局设置** | 链路概览、全局设置、通知和交互、网络代理、开发者选项。 |
| **使用手册** | 在应用内按九个主题查看操作指南。 |

外观设置可按个人习惯调整深浅与材质等选项，不影响任务规则。**全局设置 → 链路概览** 用于查看各环节配置情况；配置完成仍需一次实际任务与播放来验证，不代表整个流程已经成功。

### 三条常用流程

| 场景 | 流程 |
| --- | --- |
| 已在发现页核对媒体身份 | 选择候选与目标目录 → 原生转存、规范命名 → 正式媒体库 → STRM → Emby。 |
| 已有链接或外部下载文件 | 云下载分类暂存 → 等待稳定 → 核对身份、命名与目标 → 正式媒体库 → STRM → Emby。 |
| 外部工具已完成整理 | Webhook 核对目标和授权范围 → 定点增量 STRM → 按设置请求 Emby 刷新。 |

已有整理好的网盘库可直接从 STRM 开始。只想浏览和搜索，也可以暂不配置后续服务。

## 2. 部署与目录

### 2.1 准备与启动

需要支持 Docker Compose 的 NAS 或常驻主机。官方镜像支持 `linux/amd64` 和 `linux/arm64`，不支持 32 位 `arm/v7`；Docker 会选择对应架构。

```bash
mkdir -p media-index/data media-index/downloads media-index/strm
cd media-index
```

从本仓库下载 [docker-compose.yaml](../docker-compose.yaml) 放入工作目录。启动前将 `MEDIA_PASS` 改为自己的强密码；管理用户名由 `MEDIA_USER` 设置。修改这些启动配置后须重新创建容器使其生效。

```bash
docker compose up -d
docker compose ps
```

浏览器打开 `http://NAS_IP:8000`，将 `NAS_IP` 替换为自己的 NAS 地址。不要把示例占位直接当作地址。

| 挂载 | 保存内容 | 注意事项 |
| --- | --- | --- |
| `./data:/app/data` | 数据库、网页设置、凭据、缓存和任务状态 | 必须持久化并保持可写，不能公开上传。 |
| `./downloads:/downloads` | 使用本地输出时的任务文件 | 不等于网盘中的云下载目录。 |
| `./strm:/strm` | 生成的 STRM 及关联媒体资料 | 应让 Emby 读取同一份输出。 |

NAS 有权限要求时，在 Compose 同级 `.env` 中设置合适的 `PUID` / `PGID`。不要因权限错误反复换空数据目录，否则会表现为设置和历史消失。

### 2.2 管理端口与播放端口

| 默认端口 | 用途 | 访问方 |
| --- | --- | --- |
| `8000` | 管理面板、API、Webhook | 浏览器和对接服务。 |
| `8097` | STRM/302 播放入口 | Emby 与实际播放器。 |

端口冲突时只修改 Compose 映射左侧，例如 `18000:8000`。STRM 播放地址应填写 Emby 和播放器都能访问的实际播放映射或反向代理地址。容器中的 `localhost` / `127.0.0.1` 指向容器自身，不是 NAS 或浏览器所在电脑。

### 2.3 可选部署 PanSou

仓库 Compose 提供注释状态的 PanSou 服务与缓存卷。需要时按文件说明启用，再运行 `docker compose up -d`。同一 Compose 网络可使用 `http://pansou:8888`；已有独立服务则填写 MediaIndex 容器能访问的地址。

## 3. 第一次配置

1. **网盘工作台 → 网盘链接**：启用夸克或 115，保存自己的凭据或完成支持的登录步骤，测试连接并确认能浏览目标目录。
2. **全局设置 → 全局设置 → 影视资料服务**：填写 TMDB API Key，保存并测试。访问受限时先配置网络代理，再重测 TMDB。
3. **网盘工作台 → 资源获取**：需要站内搜索时配置 PanSou；已有链接可以先跳过。TG 频道另行配置。
4. **转存和整理规则**：核对网盘保存根、分类与命名。使用云下载整理时，再单独设置云下载根和正式媒体库根。
5. 在发现页选一部熟悉的电影，核对候选和最终目录，提交一笔小任务，在任务中心检查实际结果。
6. **STRM 与 302**：设置播放地址、输出目录与一个来源子目录，保存后执行首次全量扫描。
7. 连接 Emby，让它读取 STRM 输出，验证扫描和一次实际播放。
8. 最后逐项启用追更、愿望单、频道自动转存、定时扫描、通知、跨盘补齐和删除同步。

不用的外部服务可以保持关闭。未保存的字段不会生效；凭据显示“已配置”不等于连接始终有效。

## 4. 发现、详情与转存

### 4.1 找到目标媒体

发现页支持推荐、榜单、分类和关键词搜索。打开详情先核对标题、年份、电影或剧集类型；剧集继续核对季数和分集信息。TMDB 提供媒体资料，不提供下载文件。

媒体有同名或重制版本时，优先按年份、海报和简介确认。搜索没有结果时先检查 TMDB；有媒体资料但没有候选时，再检查 PanSou、目标网盘及过滤规则。

### 4.2 选择候选与目录

1. 在详情中选择电影或要处理的季，查看已启用网盘各自的候选。
2. 核对资源名称、画质、来源、可用季集和实际文件。多链接选择只影响本次明确勾选的资源。
3. 查看最终保存目录预演；需要修改时使用页面提供的目录选择入口。
4. 确认目标网盘和范围后提交，到 **网盘工作台 → 任务中心** 查看进度。

转存和随后的追更使用核对后的目标目录。不同网盘分别返回结果；一个网盘失败不表示另一网盘失败。没有可靠候选的网盘不会因“转存全部”自动变成成功或产生可靠资源。

需要持续关注时加入智能追更；当前没有资源时可以加入愿望单。多季内容按季处理，建议先验证一季再扩大范围。

### 4.3 待确认

“待确认”表示有线索，但还不能安全确定媒体、季集、路径或候选。打开对应条目比较候选，必要时重新搜索或暂不处理。只看到相似片名、清晰度或一个历史成功记录，不足以说明当前文件仍然正确存在。

### 4.4 提交已有链接

| 链接类型 | 对应网盘 |
| --- | --- |
| 夸克分享 | 夸克。 |
| 115 分享 | 115。 |
| 磁力、ED2K、HTTP/HTTPS 下载 | 115。 |

网页及已配置的互动渠道可接收链接。按提示选择云下载分类或已有的直接入库流程；先核对目录再确认。云下载暂存保留来源内容，完成整理后才按后处理设置进入 STRM 与 Emby。

## 5. 网盘工作台

### 5.1 网盘链接

夸克与 115 可同时使用，凭据、目录和任务分别管理。停用某个网盘会使其不再参与新的对应任务，不会删除历史文件或 STRM；切换前先连接并测试新网盘。

115 扫码登录需选择合适的终端模式；保存后，后续获取直链沿用该登录绑定。更换终端应重新完成扫码与保存，不要只修改播放器地址。

凭据失效时重新获取并保存，再测试连接即可，不需清空数据库。请勿在公开 Issue、截图或日志中贴出 Cookie。

### 5.2 资源获取：PanSou 与 TG 各自独立

**PanSou 聚合搜索**填写可从容器访问的服务地址。反向关键词只过滤 PanSou 候选，不会改写 TG 频道规则。配置失败时先检查地址、网络与 PanSou 本身的服务状态。

**TG 频道追踪**通过 Bot 接收新帖。公开或私有频道都需要将 Bot 加入频道；它不会读取加入前历史。PanSou 独立搜索其配置的公开频道，MediaIndex 导入或删除频道不会反向改变 PanSou 勾选。

每个频道分别设置：

- 是否启用、是否自动转存。
- 正向关键词：为空表示不限制；有值时命中任一项才通过。
- 反向关键词：命中任一项即拒绝，优先于正向词。
- 自动分类或明确的云下载直属分类目录。

自动分类只有在媒体类别与目标目录都唯一时执行，不明确时保留失败或待核对结果。建议先导入一两个来源、观察结果，再开启自动转存；导入来源本身不会自动开启转存。

### 5.3 转存和整理规则

分别核对各网盘的保存根、暂存位置、分类目录、命名模板和画质偏好。电影、剧集、动漫与综艺可使用不同分类。规则变更作用于后续任务，不会主动重排历史文件。

本地保存路径只用于明确选择本地输出的流程，不等于常规网盘转存目录。路径选择器可减少不同网盘路径格式造成的错误。

### 5.4 云下载整理

入口：**网盘工作台 → 云下载**。它把所选云下载分类中的原始内容，核对、改名并整理到同一网盘的正式媒体库。

1. 分别设置正式媒体库根和云下载根，两个根应互不重叠。
2. 分类使用真实存在的一级子目录。例如 `/云下载/电影` 对应 `/媒体库/电影`；这些是示例分类，可按自己目录命名。
3. 选择全部安全分类，或切换部分选择并读取、勾选范围。根目录散落文件不在分类处理中。
4. 选择前序动作事件、定时检查或两者，设置文件稳定等待与检查间隔。
5. 选择复制或移动，保存并分别启用所需网盘。先用一笔小任务核对来源和目标。

| 模式 | 结果 |
| --- | --- |
| **复制** | 规范写入正式库，保留云下载来源。 |
| **移动** | 处理计划内文件并核验目标；残留清理依据精确身份执行，异常时停止。 |

移动和清理有真实远端副作用；中途失败可能已经产生部分目标或移动了部分文件，不能理解为“完全没有修改”。遇到异常应同时查看源、目标和任务回执，避免重新提交造成重复内容。

整理必须先得到明确媒体身份、季集与命名计划。歧义、重名冲突、文件还在变化或读取失败时，停止并保留待核对；不猜测身份，也不扩大目录扫描。字幕、NFO 等只在能明确关联视频时跟随处理。

前序事件只处理本次可精确定位的目录或文件；定时模式读取已授权分类。整理完成后按各自开关执行 STRM、Emby 和通知。关闭整理开关会停止接收后续整理任务，保留配置、历史和已有文件。

### 5.5 任务中心

任务详情按真实工作流显示阶段、目标网盘和回执，不同任务的步骤可能不同。需要人工处理时，从详情进入候选或原业务页面。

| 状态 | 应怎么处理 |
| --- | --- |
| 排队、等待、等待重试 | 查看前序任务与下次时间，避免连续重复提交。 |
| 运行中 | 查看当前阶段和最近进度。 |
| 待确认、待核对 | 核对候选、文件或路径，再决定下一步。 |
| 暂无资源 | 保留愿望单或追更等待后续，或换候选。 |
| 失败、中断 | 查看已完成的远端动作与错误，再按页面入口恢复或重试。 |
| 完成 | 查看本次实际结果；请求 Emby 刷新不等于它已经完成入库。 |

## 6. 订阅与追更

### 6.1 智能追更

用于持续关注已有剧集的一季。创建时选择媒体、季、目标网盘和保存路径，先核对云端已存情况，再配置巡检时间、时区、轮询与重试策略。

追更卡片区分 TMDB 已播与当前网盘已存。自动追更按后续更新检查，不默认回补所有历史缺集；需要历史补齐时明确选择集数或使用页面给出的补集入口。

- **立即运行**：执行一次检查，不修改原计划。
- **刷新已存**：重新读取该网盘的实际内容；失败时保留原进度并显示错误。
- **生成 STRM**：只处理这条任务绑定的保存目录，不扫描整个媒体库。
- **暂停/恢复**：保留记录并控制后续自动巡检。
- **删除追更**：常规追更记录移除不等于删除网盘媒体。

人工补链时先核对链接网盘与季度。有明确手选集数时按所选处理；没有手选时，仍须依据实际已播与未存内容核验。人工候选不会绕过季集、路径和文件检查。

### 6.2 愿望单

用于尚未上线或暂时找不到可靠资源的媒体。设置检查计划与目标网盘，可逐项启用、暂停、立即检查或移除。高置信候选才会进入自动任务，其余交给人工确认。

“暂无资源”与“待确认”含义不同：前者没有合适候选，后者需要选择或核对。不要为同一目标反复添加重复条目。

## 7. 跨盘转存

侧栏入口是 **跨盘转存**，在页面中选择 **OpenList** 或 **CD2（CloudDrive2）**，一次使用一条通路。配置服务地址、Token 和两个网盘的对应根路径，保存后测试已保存的连接。

| 能力 | OpenList | CD2 |
| --- | --- | --- |
| 手动复制 | 夸克 → 115 | 夸克 → 115，或 115 → 夸克。 |
| 自动补齐 | 夸克 → 115 | 夸克 → 115。 |

手动复制先选方向、来源、文件和目标目录，再确认已有文件的处理方式，在复制队列查看结果。它会占用第三方服务流量和空间。

自动补齐先核对正式库中的夸克结果与 115 缺项；可用的原生 115 候选优先，仍缺失的精确文件才通过所选通路补齐。云下载暂存不是补齐来源；一个提供方失败不会回滚另一个已完成的结果。

## 8. STRM、302 与 Emby

### 8.1 通用设置

在 **STRM 与 302 → 通用设置** 配置：

- 播放地址：Emby 与播放器实际可访问的地址，例如 `http://NAS_IP:8097`，或指向播放端口的 HTTPS 反代。
- 输出目录：容器内路径通常为 `/strm`，由挂载映射到 Emby 读取的目录。
- Emby 地址、API Key 与自动刷新选项。

管理地址和播放地址可使用不同端口或域名。播放是否成功取决于实际客户端可达性、网盘凭据与播放链路；在管理页可访问并不能证明电视能够播放。

**STRM 文件中的 URL 是播放凭证**，不要公开分享文件、完整 URL 或带签名的截图。

### 8.2 分别配置 115 与夸克

1. 在对应网盘页面选择来源根。
2. 读取直接子目录，明确勾选要扫描的范围并保存。
3. 首次执行全量扫描，日常新增使用增量或定时增量。
4. 检查实际生成结果，再让 Emby 读取输出。

未勾选目录不会自动扫描整盘；根目录散落文件与未授权目录不纳入。两家网盘范围和任务独立。

| 操作 | 用途与边界 |
| --- | --- |
| 全量 | 首次建立、修改播放地址后更新，或核对来源与本地映射；可能按缺失确认策略清理失效的本地 STRM。 |
| 增量 | 日常新增与修复缺失的 STRM，不作为网盘删除操作。 |
| 自动 STRM | 转存后按成功目标与授权范围处理，受本页开关约束。 |
| Cron 增量 | 标准五段 Cron，例如 `0 */6 * * *` 为每六小时整点；留空关闭定时。 |

扫描生成不会移动或删除网盘媒体。删除同步是另一项显式设置。若使用 115 生活事件监控，首次启用建立基线，再按后续变化触发授权范围内的处理。

### 8.3 Emby 删除同步

115 与夸克均支持按精确 STRM 映射将对应云文件移入回收站。两者共用 Emby Webhook 密钥与 Emby 媒体库路径根，自动执行开关按网盘分别保存。

1. 先确认该媒体由当前 MediaIndex 生成 STRM 且可以正常播放。
2. 配置 Emby 事件中实际看到的 STRM 根路径；它可能不同于 MediaIndex 容器内 `/strm`。
3. 保存密钥，把页面生成的 Webhook 配置到 Emby。
4. 先保持“仅记录”，用可恢复样本核对删除意图与映射。
5. 理解副作用后，再开启对应网盘的自动执行。

关闭自动执行只记录待确认意图，不会自动回收文件。缺少映射、路径冲突或身份不明确时停止；不根据相似名称、目录名推测删除，也不执行永久删除。请保留网盘回收站的恢复窗口。

## 9. Webhook 与外部整理

入口：**网盘工作台 → Webhook**。Webhook 使用管理/API 端口。接收 `202` 只表示任务已安排或已合并，实际结果仍以任务中心为准。

### 9.1 通用连接

新建连接时选择接收或发送。页面生成独立 URL、签名密钥及测试命令；应完整保存并只交给可信服务。保存连接不等于已连通，须有真实接收或目标端成功响应。

- **通用接收**默认验证、记录消息。需要执行扫描时，明确选择“扫描指定目录并生成 STRM”，保存网盘、已授权目录、扫描模式和合并等待；外部消息不能更换目录或网盘。
- **通用发送**选择事件并填写接收地址，使用 CloudEvents JSON 与签名头发送；失败有退避重试，页面可查看最近消息和重投。
- 公网发送目标使用 HTTPS。自托管服务名与局域网地址可按页面规则配置；URL 不应嵌入用户名或密码。

### 9.2 MDC-NG

在内置 MDC-NG 设置中启用并保存密钥，选择网盘及已授权的 STRM 目录。具体完成路径只能缩小授权范围，不能扩大扫描。

| 回调模式 | 用途 |
| --- | --- |
| `mode=targeted` | 云下载整理完成后处理明确的目标文件或目录；必须带有效完成目标，缺失、无效或越界返回错误，不退回大范围扫描。 |
| `mode=metadata_only` | 原地刮削或本地资料更新，仅确认收到，不创建网盘 STRM 扫描任务。 |
| 未指定模式 | 兼容旧调用；有明确路径时按路径核验，无路径的旧配置才使用已保存兼容目录。明确路径无效时不会扩大范围。 |

例如目标目录已经位于授权范围内，可按对接工具实际支持的路径字段发送：

```bash
curl -i -X POST 'http://media-index:8000/api/webhooks/strm-incremental?mode=targeted' \
  -H 'X-MediaIndex-Webhook: REPLACE_WITH_YOUR_WEBHOOK_SECRET' \
  -H 'Content-Type: application/json' \
  -d '{"event":"finished","target_path":"/媒体库/电影/示例作品"}'
```

示例目录必须替换为自己已保存授权范围内的真实完成目标。优先用请求头传密钥，避免进入访问日志；必须使用带 `token` 的兼容 URL 时，把完整地址当作凭据保护。页面的“只测试连接与凭据”不会安排真实扫描，外部实际完成回调会安排任务。

### 9.3 bili-sync

推荐建立独立的接收连接，选择保存好的 STRM 目录与合并等待，将页面生成的接收 URL 和密钥填写到 bili-sync。等待时间需覆盖上传到网盘后的可见延迟。独立兼容入口也可继续使用，但不要与 MDC 的目录设置混用。具体配置值使用自己的地址和密钥，勿复制其他部署的回调 URL。

## 10. 媒体服务器与封面

**媒体服务器**展示 Emby 连接、媒体库、用户、播放会话和最近入库。连接配置仍需保存并测试；MediaIndex 不替代 Emby 的媒体库、用户、刮削和转码设置。

封面工坊的推荐操作：选择一个媒体库 → 调整风格、尺寸、标题和取图方式 → 重新取样预览 → 确认后替换当前库，或替换所选库。预览不写入 Emby，替换和定时任务会实际修改封面。

可按页面配置每个库的中英文标题、海报或背景图、排序、背景、字体与比例。上传字体应使用自己有权使用的文件；先验证单库，再开启批量与定时更新。定时任务只处理已配置的范围，避免不需要的封面反复变化。

## 11. 通知、日报与免打扰

入口：**全局设置 → 通知和交互 → 通知**。

1. 配置外部消息总开关与事件类别。
2. 按需配置企业微信自建应用、机器人或 Telegram，保存后发送渠道测试。
3. 有消息跳转、回调或图片访问需求时，填写相应服务实际可访问的公网地址。
4. 在“推送时间”设置每日运行报告和免打扰。

| 设置 | 行为 |
| --- | --- |
| 每日运行报告 | 默认启用、21:00，沿用追更时区；汇总上一个设定时点至本次的任务运行情况。首次启用从下一个时点开始，不补发旧报告。 |
| 常规维护进度 | 站内保留并汇入日报；入库、失败等仍按所选事件类别推送。 |
| 免打扰 | 默认关闭，预设 22:00–08:00，可改为跨午夜时段；开始与结束不能相同。 |
| 免打扰期间 | 自动外部推送延后；站内通知照常，主动互动和手动渠道测试仍即时响应。 |

Emby 入库播报基于实际事件与核验结果，剧集按已确认季集聚合，不把“已请求刷新”当作“全部入库”。图片暂缺时会等待可信图片，仍不可用则回退文字；正文聚焦媒体身份与入库结果。测试消息不等于真实 Emby 回调验证。

### 企业微信与 Telegram

- 企业微信自建应用填写自己的企业与应用参数、接收范围；机器人适合群内通知。需要接收成员指令时配置自建应用回调。
- Telegram 填写 Bot Token、Chat ID，并确认 Bot 有对应会话权限。频道追踪需要另将 Bot 加入频道。
- 企业微信“消息代理地址”用于发送消息，不等于应用回调地址。
- 回调需要从平台访问到管理入口，检查 HTTPS、密钥以及反向代理是否保留查询参数。

## 12. 聊天交互与云下载设置

在 **全局设置 → 通知和交互** 中切换“交互指令”和“云下载设置”。先保存渠道，再设置允许网盘、路径与常用指令。可把快捷项同步到平台菜单，实际可用项以 `/help` 为准。

| 输入 | 用途 |
| --- | --- |
| 媒体名称 | 搜索候选，按回复选择媒体、资源和目录。 |
| 分享或下载链接 | 按网盘类型和已授权目录接收。 |
| 数字、按钮 | 选择当前会话候选、目录或确认步骤。 |
| `/review`、`/status` | 查看待确认或最近任务。 |
| `/tracking`、`/wishlist` | 查看追更与愿望单。 |
| `/strm_full`、`/strm_incremental`、`/strm_directory` | 对允许网盘执行相应 STRM 操作。 |
| `/cancel`、`/help` | 取消当前选择步骤、查看帮助。 |

数字只对应当前会话最近的待选择步骤。列表变化或会话过期后重新发起，不要沿用旧数字。链接、转存确认与 STRM 指令可能产生真实任务；先用自己有权处理的小样本验证。

## 13. 全局设置、代理与配置迁移

### 网络代理

在 **全局设置 → 网络代理** 填写容器可访问的完整代理地址，再保存、测试代理和受影响的服务。代理需允许 NAS 访问；不要把浏览器电脑上的回环地址填入 NAS 容器。

Compose 也支持 `PROXY_URL` 与标准代理环境变量；网页保存的同名代理设置优先于启动默认值。修改代理不表示每个第三方服务都会成功，仍需分别测试。

### 配置导入导出

导出 JSON 包含设置、任务和敏感凭据，可用于应用级迁移，但不能替代整个 `data` 与 STRM 目录备份。导入前先导出当前配置，确认来源可信，并理解“覆盖”会替换同类配置和任务。

### 远程只读诊断

**全局设置 → 开发者选项**默认关闭。确需支持时，按页面创建短期只读诊断令牌，限定有效期并在结束后撤销。它不是后台密码，不应为排障提供管理账号、Cookie 或永久 Token。分享前仍需检查输出是否包含自己的媒体名称、路径与身份线索。

## 14. 升级、备份与恢复

升级前备份 `data`、`strm`、使用中的 `downloads`、Compose 和同级 `.env`。为得到一致的数据库备份，优先停止写入或停止容器后复制，并记录当前镜像版本。导出配置 JSON 只是补充。

```bash
docker compose pull
docker compose up -d
docker compose ps
docker compose logs --tail=100 media-index
```

升级后检查登录、网盘连接、历史任务、追更与愿望单，再验证一个既有 STRM 的实际播放。查看 [更新日志](../CHANGELOG.md) 与对应 Release，按版本要求处理兼容事项。

从很早的双容器部署迁移时，使用当前单容器双端口 Compose，保留原持久化目录，移除不再使用的独立播放容器。播放地址变化后需更新 STRM。

回滚前核对旧镜像与当前数据库兼容性，优先使用升级前的完整备份和明确版本镜像。不要只回滚部分数据库文件，也不要用空数据目录伪装恢复成功。

## 15. 常见问题

| 现象 | 检查顺序 |
| --- | --- |
| 设置重启后丢失 | 是否仍挂载原 `data`，路径和读写权限是否正确。 |
| 连接失败或目录读不到 | 凭据有效性、服务可达性、容器时间、账号限制与实际目录。 |
| TMDB、Telegram 无法访问 | 容器网络、可访问的代理地址、服务单独测试结果。 |
| 搜到媒体却没有资源 | PanSou 连接、目标网盘、候选过滤；资料与下载来源是两回事。 |
| 追更集数不符 | 季数与播出日期、保存目录、文件命名；先“刷新已存”，再决定补集。 |
| 云下载不整理 | 网盘整理开关、授权分类、触发方式、稳定等待、TMDB 识别与任务回执。 |
| STRM 缺失 | 来源根与勾选目录、输出权限、任务结果；确认范围后执行相应扫描。 |
| 能入库却不能播放 | STRM 中地址与播放端口，Emby 和客户端可达性、网盘登录与代理。 |
| Emby 没有入库通知 | 真实入库回调、事件配置、推送开关、免打扰和渠道回执；刷新请求不是入库回执。 |
| 删除同步不执行 | 对应网盘自动开关、Emby 事件路径、精确映射与待确认意图；不要放宽名称匹配。 |
| Webhook 错误 | `401` 查密钥，`409` 查开关与配置，`422` 查模式和明确目标，`503` 查服务或排队。 |
| 队列长时间不动 | 当前阶段、账号冷却、前序任务与失败原因；不要连续反复提交。 |
| 封面预览或替换失败 | Emby 连接、可用图片与字体，先单库低分辨率预览，再检查写入回执。 |

清除历史只影响对应终态记录的显示，不等于停止活动任务或删除媒体；停止运行需使用可停止任务的专门入口。操作前阅读当前按钮及确认提示。
